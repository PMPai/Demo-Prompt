# 好的提示词 
## 第一性原理
- 自己必须非常清楚想要是什么。
- 预期的输出 < 完整的提示词 <清楚的思想。

大部分人开始都搞错了，一有想法就想直接对AI提问，但是AI只能天马行空地给你一些答案，反而更浪费你的资源。所以真正要做的方式，事先坐下来考虑如何有效的把你的思维和意图，系统并且逻辑表达出来。

## 提示词工程
6R 
| **分类**| **内容**|
|:---|:---|
|Role| 角色确定|
|Request| 工作确定|
|Resource|可用资源|
|Restrain|预先警告|
| Result|输出方式|
|Reference|参考案例|

一个好的技巧就是使用AI来作为你的引导，能够把你最初的想法、大概的需求、考虑的方式以及想要的结果，全部一股脑地用语音方式输出给AI，然后让AI使用 6R的提示词 SKill 先做一个整理，系统输出。 之后在这个输出上面在不断的迭代细化。
